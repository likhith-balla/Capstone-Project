Titanic Dataset - Data Cleaning & Exploratory Analysis

An end-to-end Python project focused on importing, cleaning, transforming, and preparing the famous Titanic dataset for data analysis and visualization.

Project Overview

This project loads the raw Titanic dataset using Seaborn, performs data preprocessing to address missing values and structural inconsistencies, and exports both the raw and cleaned datasets into an organized `analytics/` folder.

Key Objectives
* Automatically fetch raw data via seaborn.load_dataset.
* Handle missing values across key features (e.g., age, `embarked, deck).
* Export clean, analysis-ready CSV files for downstream reporting or machine learning pipelines.
