Catalog Data Pipeline Project

Project Overview

This project is an end-to-end data engineering pipeline built in Google Colab. It scrapes product catalog data from books.toscrape.com, cleans and standardizes the attributes, enriches the pricing data using a fixed currency conversion rate, and stores the structured data into a normalized SQLite relational database.

Files in this Repository

data_pipeline.ipynb: The main notebook containing all Python code for web scraping, data cleaning, database loading, and data analysis.
books_catalog.db: The SQLite database generated by running the pipeline.
requirements.txt: List of Python packages required to run the notebook.

How the Pipeline Works

1. Data Scraping: Uses the Requests and BeautifulSoup libraries to collect product titles, prices in GBP, star ratings, and stock availability across multiple categories.
2. Data Cleaning: Strips currency symbols to create a numeric price field, converts text ratings (One to Five) into numbers (1 to 5), and converts stock text into simple flags.
3. Error Handling: Missing or corrupted numeric fields are filled using category-level median prices to preserve dataset size without skewing averages.
4. Currency Conversion: Prices are converted from GBP to INR using a fixed baseline exchange rate of 105.50 INR per 1 GBP.
5. Database Storage: Loads the cleaned data into an SQLite database structured into two linked tables: Categories and Books.
6. SQL & Pandas Benchmarking**: Runs analytical queries using SQL joins, filters, and aggregations, and verifies that Pandas merge functions produce identical results.

How to Run

1. Open the notebook in Google Colab.
2. Select Runtime from the top menu and click Run all.
3. The pipeline will automatically fetch the data, build the database, and execute all test queries.
